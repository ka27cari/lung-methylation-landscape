# Release scope

- **Included:** analytical source code, scripts for producing Source Data, configurations, R package inventory, synthetic unit tests and a small aggregate numerical fixture.
- **Distributed as separate publication files:** Source Data workbook and figure-specific machine-readable numerical tables.
- **Not included:** individual participant records, methylation matrices, cohort case/control labels, exact collection/diagnosis dates, locally generated RDS objects and raw/subject-level caches.
- **Not presumed freely redistributable:** cohort-derived reference-model parameter archives; institutional approval is required before depositing these independently.

For the published analysis, the complete computational workflow depends on controlled-access input datasets from the underlying cohorts. The standalone repository is not a substitute for those inputs. The author is responsible for choosing a license and a permanent archival identifier after release.
